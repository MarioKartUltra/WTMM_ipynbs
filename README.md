# WTMM_ipynbs

Test notebooks for the WTMM / wavelet work (EBSD, InSAR, shear zones, xsmurf wrappers, synthetic
signals) with the figures they produce. A lot of things here are obviously the process of trial and error and troubleshooting. Check the GeoDynamX repo for the correct codes that came as a result of these sessions. Tensorial WTMM has not yet been ported to native python, and I was using a wrapper for xsmurf (https://github.com/pkestene/xsmurf).
